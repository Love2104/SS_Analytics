## **Spring Street – Full Stack Internship Assignment** 

## **Objective** 

Build a market insights and portfolio analytics tool that demonstrates your ability to work on frontend, backend, or both, with a strong emphasis on visual creativity, design quality, meaningful animations, and customer-friendly UX. 

## **Problem Statement** 

Build a Market Insights & Portfolio Analytics Dashboard using real market data. Create an equal-weighted portfolio consisting of 3–5 tickers of your choice, and generate insights based on historical market performance. 

## **Data Source** 

You may use Yahoo Finance to fetch 5 years of OHLC data for the selected stocks or ETFs. 

## **Frontend Requirements (High Priority)** 

- Use any Frontend Framework of your choice (Preferred: React.js / Next.js) 

- Use any visualization library 

- Display 5-year OHLC price insights 

- Create portfolio analytics using an equal-weighted portfolio (portfolio value, asset contribution, basic metrics) 

## **Design & UX Expectations** 

- Strong visual hierarchy and layout 

- Meaningful animations and transitions 

- Customer-friendly interactions 

- Clear loading, empty, and error states 

## **Backend (Optional but Bonus)** 

- Use Python or Go to fetch and process data 

- Expose REST APIs for frontend consumption 

## **Evaluation Criteria** 

- UI/UX quality and visual creativity 

- Data visualization clarity and insight generation 

- Frontend fundamentals 

- Backend integration (if applicable) 

- Code quality and completeness 

## **Submission Instructions** 

- Push code to a public GitHub repository 

- Include README with setup steps, explanation of insights, and screenshots 

- Submission link and deadline will be shared separately
